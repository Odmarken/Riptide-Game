# Spanish (Spain) - terminology decisions (from the terms pass, 2026-10-13)

The full glossary is terms-01..04.json in this folder; these are the decisions behind it.

1. Address the player as tú. Sentence case for labels, spells, talents and items ("Bola de fuego", "Golpe heroico"). ALL-CAPS stays caps.
2. Prestige = Prestigio ("P{n}" stays). Level/Lv = nivel/Nv., XP = PX, HP/MP = PV/PM, ATK/CRIT = ATQ/CRÍT, Rating = puntuación, Tier = grado ("Pergamino · Grado II").
3. Tide/Tides (the creatures) stay as the brand name, masculine: un Tide, los Tides, Gremio de Tides, Combate de Tides, Maestro de Tides.
4. Sea/church tides = "mareas": Tidekeeper = el Guardamareas, Tides Bank = Banco de las Mareas, University of the Tides = Universidad de las Mareas.
5. Crown Ledger = el Libro Mayor de la Corona. Ledger = libro mayor, a close = un cierre, season = temporada, treasury = el Tesoro.
6. City: in the red = en números rojos, Master of Coin = Consejero de la Moneda, steward = administrador, the Hand = la Mano, council = consejo, public works = obras públicas.
7. Gold ◉ = oro ("{n} de oro"). Scraps ⚙ = chatarra, to scrap = desguazar, scrap pouch = bolsa de chatarra. The food-budget level "Scraps" = "Sobras".
8. Peerage: Caballero/Dama, Barón/Baronesa, Vizconde/Vizcondesa, Conde/Condesa, Marqués/Marquesa, Duque/Duquesa, Rey/Reina, Emperador/Emperatriz. Commoner = Pueblo llano, Patent of nobility = Carta de nobleza. Lord/Lady/Sir/Jarl stay in front of names.
9. Classes and races: Guerrero, Mago, Cazador, Sacerdote; Humano, Enano, Orco, No muerto. Specs: Berserker/Guardián, Piromante/Custodio de escarcha, Tirador/Guardabosques, Zelote/Santuario.
10. Places: la Ciudad, el Puerto (Harbour and Port), la Granja, el Yermo (Wasteland), Hogar (Home), Salón del Trono, El Altar, Las Criptas, La Hora Final, Nivel de las Vacas.
11. Coined names stay, only the descriptive part is translated: Moonshine, Silverfjord, Ravenholt, Emberfall, Port Meridian, Kraken’s Rest; "Campos de Willowmere", "Posada Moonshine", "Casino Riptide".
12. Blackbeard = Capitán Barbanegra, the Black Tide = la Marea Negra, Odin = Odín. Thor, Valhalla and Mjolnir unchanged. The Forsaken / the Forsaken One = los Repudiados / el Repudiado.
13. Free Company = Compañía Libre, sellsword = mercenario. The watch, Watchman, Guardsman and Guard = guardia/Guardia; Royal Guard = Guardia Real.
14. Raid (incl. port raids) = incursión ("Incursión en {port}"). Dungeon = mazmorra, boss = jefe, foe = enemigo, mount = montura, pet = mascota, companion = compañero, outfit = atuendo, King's robes = Manto del Rey.
15. Chest = cofre, shop case = caja, bag = bolsa, gear = equipo, trinket = abalorio, enchant = encantamiento, scroll = pergamino.
16. Casino: slots = tragaperras, spin = girar/giro, FREE SPINS = GIROS GRATIS, jackpot = BOTE, dealer = crupier. Blackjack: Pedir/Plantarse/Doblar/Repartir. "No va más", "Hagan juego". GOLD GOLD GOLD = ORO ORO ORO, GAMBAAA! = ¡TIMBAAA!.
17. NPC titles before the name: Mercader, Comerciante, Vendedora, Tendera, Panadera, Pescadera, Marinero, Estibador, Herrero, Fray/Sor, Maese, Señorita, Escudero, Oficial. Nicknames after: Rurik el Negro, Sixten el Tuerto.
18. Controls (Spain): mando, cruceta, stick izquierdo/derecho, ratón, clic derecho, Vista/Menú for View/Start. Settings = Ajustes, Video = Vídeo.
19. Shared keys: "Scroll" = Pergamino (also the stick's "Scroll" line), "Worn" = Usado, "All" = Todos. Item names are built "Prefix Base" and shown word by word: lower-case masculine bases, prefixes that can come first. "s are" = "s son" (in "Your next {0} case{1} free." write "caja{1}").
