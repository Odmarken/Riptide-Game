# Italian - terminology decisions (from the terms pass, 2026-10-13)

The full glossary is terms-01..04.json in this folder; these are the decisions behind it. Address the player as "tu"; use the curly apostrophe ’.

1. Prestige = Prestigio ("P{n}" stays). Level = Livello / Liv. XP / HP / MP / ATK = PE / PS / PM / ATT; CRIT stays. Health = Salute.
2. Tide (the creatures) stays "Tide", masculine, same in the plural: il Tide, i Tide, Gilda dei Tide, Maestro dei Tide, Deposito dei Tide. Breeding = allevamento (Breeder = Allevatore); Trainer = Addestratore; companion = compagno.
3. Tides Bank = Banca delle Maree. The Black Tide (the ship) = la Marea Nera.
4. Crown Ledger = Registro della Corona (Ledger = Registro). A close = chiusura ("Every close" = "A ogni chiusura"). Season = stagione, Treasury = Tesoreria, Debt = Debito, Budget = Bilancio, Works / Public works = Opere / Opere pubbliche, jail = carcere, Council = Consiglio.
5. The King's Hand / the Hand = il Primo Cavaliere; his counsel = "parere" (not Consiglio). Master of Coin = Maestro del Conio, Lord Commander = Lord Comandante, Master Builder = Capomastro, High Almoner = Grande Elemosiniere, Master of Revels = Maestro delle Feste, Lord Chamberlain = Gran Ciambellano. Comptroller = Sovrintendente. Margrave = Margravio; Jarl stays.
6. Peerage: Popolano, Cavaliere / Dama, Barone / Baronessa, Visconte / Viscontessa, Conte / Contessa, Marchese / Marchesa, Duca / Duchessa, Re / Regina, Imperatore / Imperatrice. Patent of nobility = patente di nobiltà. Lady, Lord and Sir stay.
7. Races: Umano, Nano, Orco, Non morto. Classes: Guerriero, Mago, Cacciatore, Sacerdote.
8. Gold = oro: "{n} oro" in labels, "monete d’oro" in sentences. Scraps (⚙) = rottami; to scrap = smantellare; scrap pouch = sacca dei rottami. The City food level "Scraps" = Avanzi.
9. City = la Città. Harbour / Port = il Porto (Harbourmaster = Capitano di porto). Wasteland = Landa Desolata. Farm = Fattoria. Throne Hall = Sala del Trono. Cow Level = Livello delle Mucche. The Altar = L’Altare. The Final Hour = L’Ora Finale. Valhalla stays; Odin = Odino; Blackbeard = Capitan Barbanera.
10. Coined names stay as written (Moonshine, Ravenholt, Silverfjord, Emberfall, Port Meridian, Kraken’s Rest, Briarhollow, Cindervein, Frostveil, Frostseeker). Mixed names: translate the plain part only ("Valle di Shatterstone", "Rocca di Emberdeep").
11. The Forsaken = i Reietti; The Forsaken One = il Reietto. Fel = Demoniaco ("Fel Glaives" = Lame Demoniache, "Fel Lord" = Signore Demoniaco).
12. Free Company = Compagnia di Ventura. Sellsword = Mercenario. Watchman / Guard = Guardia; City Watch = Guardia cittadina.
13. Raid = Incursione. Dungeon and boss stay. Mount = cavalcatura (Monta / Smonta). Pet = Mascotte. Bag = Borsa. Gear = Equipaggiamento; to equip = Equipaggia / Equipaggiato.
14. Spell = incantesimo. Talent = talento. Skill Tree = Albero delle abilità. Enchant = incantamento. Scroll = pergamena; Tier = Grado. Rarities: Comune, Pregiato (Fine), Raro, Epico, Leggendario, Mutante.
15. Ring = l’Anello, Ice Armor = Armatura di Ghiaccio, Book of Knowledge = Libro della Conoscenza. Blacksmith = Fabbro, Forge = Forgia, Furnace = Fornace.
16. Casino: spin = giro / Gira, free spins = giri gratis, BIG WIN = GRANDE VINCITA, bet / stake = puntata, dealer = banco. Rating = Punteggio.
17. Spells, talents, items, monsters, Tide species and buttons in sentence case ("Palla di fuoco", "Colpo eroico"); places, institutions and ships capitalised ("Landa Desolata", "Banca delle Maree", "La Marea Nera").
18. Prefer wording that works for either gender where natural; otherwise the standard masculine.
19. Item names are built "Prefix Base" and shown word by word (adjective first): prefixes chosen to read well before the noun. "Worn" = Usato.
