# Russian - terminology decisions (from the terms pass, 2026-10-13)

The full glossary is terms-01..04.json in this folder; these are the decisions behind it.

1. Address the player as вы (lower case). Write ё. Use " — " for dashes inside sentences.
2. People's names and coined place names stay in Latin letters; titles and nicknames in front are translated: Король Alarik Tidvind, Боцман Figge, Одноглазый Sixten.
3. Zone names with a coined word stay Latin (Willowmere Fields, Ironcrag Pass, Sunscar Sands). Plain ones are translated: Пустошь, Склепы, Алтарь, Последний час, Тронный зал, Коровий уровень, Чертоги Вальхаллы, Западные земли.
4. Prestige = Престиж (P5 = П5). Lv/Lvl = Ур. XP = опыт (HUD label ОП); HP = ОЗ; MP = ОМ.
5. Tide (the creature) = тайд, animate ("выберите тайда"), plural тайды/тайдов: Гильдия тайдов, хранилище тайдов, битва тайдов, Мастер тайдов. Companion = спутник.
6. Sea "Tide" names: Tides Bank = Банк Приливов; the ship Black Tide = Чёрный прилив.
7. Crown Ledger = Гроссбух короны; Ledger = Гроссбух.
8. The five-minute city "close" = расчёт ("каждый расчёт", "расчётов в минусе"). Season = сезон; treasury = казна.
9. The Hand = Десница; Master of Coin = Мастер над монетой; steward = управитель; council = совет; regency = регентство.
10. Public works = городские стройки (the Works tab is Стройки).
11. Gold (◉) = золото. Scraps (⚙) = лом ("50 лома"); to scrap = разобрать; scrap pouch = мешок для лома.
12. Peerage: Простолюдин; Рыцарь/Дама; Барон/Баронесса; Виконт/Виконтесса; Граф/Графиня; Маркиз/Маркиза; Герцог/Герцогиня; Король/Королева; Император/Императрица. Patent of nobility = дворянская грамота.
13. Classes: Воин, Маг, Охотник, Жрец. Races: Человек, Дворф, Орк, Нежить.
14. City = Город; Harbour = Гавань; harbourmaster = начальник гавани; Port = Порт; Farm = Ферма. Moonshine stays Latin (Трактир Moonshine).
15. Forsaken = Отрёкшиеся; the Forsaken One = Отрёкшийся. Fel = Скверна.
16. Тор, Один, Вальхалла, Мьёльнир; Blackbeard = Чёрная Борода (Капитан Чёрная Борода).
17. Free Company = Вольный отряд; sellsword = наёмник.
18. City Watch = Городская стража; watchman = стражник; guard = страж; guardsman = гвардеец; cadet = кадет.
19. Enchant = чары; Enchanting = Зачарование; scroll = свиток; Tier = ранг.
20. Mount = скакун; pet = питомец; Equip/Equipped = Выбрать/Используется.
21. Spells use the familiar WoW Russian names: Удар героя, Огненный шар, Кольцо льда, Залп, Кара, Кольцо света, Обновление. Arcane = чародейский.
22. Rarities masculine: Обычный, Хороший, Редкий, Эпический, Легендарный.
23. Random item names are joined word by word: every prefix a masculine adjective, every base a lowercase masculine noun (клинок, протазан, лук, скипетр, доспех, панцирь, плащ, щит, перстень, талисман, рог, идол).
24. Raid = рейд; a raid on a port = набег; dungeon = подземелье; boss = босс; Hardcore = хардкор; AUTO = АВТО.
25. Casino: крутить/спин, фриспины, джекпот, крупный выигрыш, ставка. A case (loot box) = кейс; a chest = сундук.
26. Shared keys: "Worn" = Потёртый (also the worn-outfit button), "Close" = Закрыть (also the season table's "Close" column).
